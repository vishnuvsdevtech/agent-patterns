    What each run proves

    Limits, stated rather than discovered

    The brain in these traces is a rule set, not a model — that is why the whole thing runs with no key, no network and no cost, and why every routing decision shows its weights. ModelBrain has the same three methods and calls an OpenAI-compatible endpoint when DEEPSEEK_API_KEY is set; the harness around it does not change, which is the point: routing, retries, judging and tracing are harness work, not model work. The tools are local fixtures, so the 503s are injected, not real outages — the retry path is real, the outage is simulated.
